# 背景音乐 / BGM

本站背景音乐歌名：**《忘了》**。

## 如何使用真实音频
把音频文件命名为 **`forgot.mp3`** 放到本目录（即 `assets/music/forgot.mp3`），
页面右下角 🎵 按钮播放时会自动加载并使用它。

- 格式：mp3
- 文件名：固定为 `forgot.mp3`
- 建议时长循环友好、音量适中

## 兜底说明
若本目录暂无真实音频文件，页面会用 **Web Audio API 合成的轻柔演示旋律** 兜底播放，
歌名显示为「忘了（演示旋律）」。放入上面的 `forgot.mp3` 后，演示旋律会被自动替换。
