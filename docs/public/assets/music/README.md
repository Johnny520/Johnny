## 如何使用
把上面 4 个 mp3 文件放到本目录（即 `assets/music/`），
点击页面右下角 🎵 按钮即开始**随机播放**，一首播完自动随机切下一首。

## 兜底说明
若本目录暂无真实音频文件，页面会用 **Web Audio API 合成的轻柔演示旋律** 兜底，
放入上面的 mp3 后，演示旋律会被自动替换为真实歌曲的随机播放。

> 注意：请仅放入你拥有合法使用权/已授权的音频，勿放入未授权音乐。
