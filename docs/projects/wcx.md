# 💬 WCX · 微信增强模块

> 一个集成了微信 Xposed 模块与去混淆分析工具的综合项目

## 简介

**WCX** 是我在维护的微信增强模块项目，把微信 Xposed 模块与去混淆分析工具整合在一起。

模块当前有 **200+ 个功能开关**，分为 20 余个分类，全部可以在设置里按分类单独打开或关闭；每个功能都带独立说明，可在线查看。

## 亮点

- **防撤回两种样式**：新版「原消息半透明 + 文本 / 图标徽标」，或旧版「插入系统提示」；二者互斥，历史旧提示可一键迁移为新样式
- **脚本插件中心**：本地插件启用 / 停用 / 排序 / 导入，在线市场浏览与安装，改完文件约 0.5 秒自动重载；附诊断、常见问题、一键自检与一键修复
- **在线特征包**：微信更新后 Hook 点特征可在线更新，不必等模块重新发版
- **稳定性工具**：模块自检（功能 / 微信 API / DexKit 任务 / 关键锚点）、「上次退出原因」、分级日志
- 全部自签名发版，跟随微信版本迭代

## 适配版本

- 推荐使用 **微信 8.0.77 ~ 8.0.79**（维护中：8.0.69 ~ 8.0.76）
- 框架：LSPosed（推荐）；架构：arm64-v8a / armeabi-v7a
