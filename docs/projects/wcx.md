# 💬 WCX · 微信增强模块

> 一个集成了微信 Xposed 模块与去混淆分析工具的综合项目

## 简介

**WCX** 是我在维护的微信增强模块项目，把微信 Xposed 模块与去混淆分析工具整合在一起。

## 能做什么

- 微信功能增强（模块化开关，按需启用）：聊天增强、界面美化、隐私防护、红包助手、AI 自动回复等
- **脚本插件中心**：独立的「脚本」Tab，支持本地插件管理与在线插件市场，插件修改后实时加载；并附带功能诊断、常见问题、一键自检与一键修复
- 内置去混淆 / 分析工具链
- 全部自签名发版，跟随微信版本迭代

## 适配版本

- 推荐使用 **微信 8.0.77 ~ 8.0.79**（维护中：8.0.69 ~ 8.0.76）
- 框架：LSPosed（推荐）；架构：arm64-v8a / armeabi-v7a
