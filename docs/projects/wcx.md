# 💬 WCX · 微信增强模块

> 一个集成了微信 Xposed 模块与去混淆分析工具的综合项目

## 简介

**WCX** 是我在维护的微信增强模块项目，把微信 Xposed 模块与去混淆分析工具整合在一起。

## 能做什么

- 微信功能增强（模块化开关，按需启用）
- 内置去混淆 / 分析工具链
- 全部自签名发版，跟随微信版本迭代
