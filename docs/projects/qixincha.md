# 🏢 企信查 · 企业信息查询

> 类天眼查风格的企业信息查询 App（Web / Android / Flutter 三端）

## 简介

**企信查** 是一套类天眼查风格的企业信息查询应用，提供 Web、Android 原生与 Flutter 三个版本。

## 三端

| 版本 | 技术 |
| --- | --- |
| 企信查 Web | Python |
| 企信查 Android | Java 原生（官方 SDK，兼容 Android 7–16） |
| 企信查 Flutter | Dart / Flutter 重写版 |
