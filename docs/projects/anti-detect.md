# 🛡️ Anti-Detect · 反检测模块

> Zygisk 反检测模块 —— 隐藏 Root / Magisk / Xposed / LSPosed / KernelSU / Bootloader 解锁

## 简介

**Anti-Detect** 是一个基于 **Zygisk** 的反检测模块，用于隐藏设备上的 Root 与模块痕迹，让 App 检测不到。

## 隐藏目标

- Root
- Magisk
- Xposed / LSPosed
- KernelSU
- Bootloader 解锁状态
