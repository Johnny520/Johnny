# 🧹 分区清理大师

> Root 分区清理工具：分区扫描、垃圾 / 空文件夹 / 重复文件清理

## 简介

**分区清理大师** 是一个面向 Root 设备的分区清理工具，帮助你梳理系统分区空间占用并清理无用文件。

## 功能

- 分区扫描（查看各分区空间占用）
- 垃圾文件清理
- 空文件夹清理
- 重复文件清理
